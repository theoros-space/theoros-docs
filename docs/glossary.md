# Glossary

| Term | Meaning |
|---|---|
| Band | One spectral channel of a camera, defined by its wavelength range |
| GSD | Ground sample distance: the size of one pixel on the ground |
| L1C | Top-of-atmosphere reflectance product, close to what the satellite sees |
| Downlink | Data sent from the satellite to a ground station |
| Ground pass | One window in which a satellite can talk to a ground station |
| Flight graph | The static network that runs on the satellite |
| Sensor profile | Bands, bandwidths, GSD and calibration of one instrument |
| Tier | Model size class: nano, base or max |
| ICD | Interface control document |
